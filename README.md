# Домашнее задание 1: персональные top-10 рекомендации

**Студент:** Солодова Дарья Сергеевна.

**Датасет:** [UCI Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail),
Daqing Chen (2015), [DOI: 10.24432/C5BW33](https://doi.org/10.24432/C5BW33), CC BY 4.0.
Рекомендуем ещё не купленные товары существующим покупателям.

## Запуск

Python **3.12**, CPU; рекомендуется 4 ГБ свободной RAM.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run_experiments.py
```

На Windows активация: `.venv\Scripts\activate`.
Данные (~23 МБ) автоматически скачиваются из UCI при первом запуске в `.cache/`;
контрольная сумма проверяется по `dataset_manifest.json`.
Путь к кешу можно переопределить переменной окружения `RECSYS_CACHE`.
Нужен доступ к интернету только для установки зависимостей и первой загрузки данных.
Скрипт выполняет все ячейки и сохраняет таблицы и графики прямо в `experiments.ipynb`.
Также можно открыть ноутбук в VS Code/Jupyter с ядром созданного окружения и выполнить Run All.

## Содержание

- `experiments.ipynb`: постановка, EDA, временной протокол, формулы, validation-поиск,
  финальный test, ablation метаданных, парный bootstrap и выводы.
- `models/`: пять собственных реализаций — ItemKNN, iALS, EASE, FM, iALS с таргетом повторных покупок.
- `data_utils.py`: загрузка, очистка и признаки только из train.
- `evaluation.py`: единое ранжирование полного каталога и метрики.
- `experiment_utils.py`: заранее заданные пространства поиска.
- `tests/test_correctness.py`: проверка метрик, ALS normal equations, FM-формулы и исключения известных товаров.
- `results/`: небольшие агрегированные таблицы и параметры; сравнения моделей.

Основная метрика заранее выбрана: **NDCG@10**; дополнительные: Recall@10,
Precision@10 и Coverage@10. Фиксированные seed=42 и один поток BLAS.
Веса после подбора не дообучаются: это сравнение замороженных моделей с учётом
известной на начало test истории при исключении уже купленных товаров.

## Полученные результаты

После очистки: **391 150 строк**, **4 334 пользователя**, **3 659 товаров**.
Обучение: 223 127 строк, 162 426 уникальных user-item пар. Test: 1 229 пользователей.

| Модель | NDCG@10 | Recall@10 |
|---|---:|---:|
| EASE | 0.07767 | 0.05464 |
| iALS с кастомным таргетом | 0.06452 | 0.04718 |
| iALS | 0.06387 | 0.04672 |
| ItemKNN | 0.05831 | 0.04003 |
| FM с метаданными | 0.05491 | 0.03504 |

EASE лучший в этом эксперименте. Доверительные интервалы эффекта кастомного таргета
и метаданных включают ноль. Подробная ablation, параметры и ограничения — в ноутбуке.

Проверка реализации:
```bash
python -m unittest discover -s tests -v
```
Восемь тестов проверяют формулы моделей, градиент FM, временную фильтрацию и метрики.
